# 🌾 Delight Legacy

**Delight Legacy** is an **unofficial, fan-made backport** of [Farmer’s Delight](https://github.com/vectorwing/FarmersDelight) for Minecraft **1.7.10**.

This mod exists simply because I wanted it to. It’s not official in any way, and updates depend on how much energy and time I’ve got to keep it going.

---

## ⚠️ Disclaimer

> Just to be clear — this is not an official mod.
> It’s **not made by vectorwing**, the original creator of Farmer’s Delight.
> They’re **not responsible** for anything here.
> This is a fan project, made independently, to bring the experience to legacy Forge versions.

---

## 📜 About

- Rebuilds the core mechanics of Farmer’s Delight for older Minecraft version  
  - Targeted at 1.7.10
- Rewritten from scratch to work within the limits of those older versions
- Aims to feel familiar if you’ve used the original mod, just... with some version quirks
